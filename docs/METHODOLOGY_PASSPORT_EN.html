2. Research Type

Quantitative (Experimental, Comparative).

All scientific conclusions are founded upon objective, measurable numerical metrics (detection accuracy, inference latency in milliseconds, memory consumption in megabytes) obtained in a strictly controlled computational experiment with varied independent factors (model architecture / data representation). Hypotheses are tested using non-parametric inferential statistics (paired Wilcoxon signed-rank test, significance level α = 0.05). The qualitative component (literature review in Task 1, Zotero Base, ResearchRabbit LitMap) is used exclusively to substantiate hypothesis thresholds and to select fair baseline models.

3. Formulation of Hypotheses (Refined for Week 5)

Zero-Day Evaluation Protocol: leave-one-attack-out. Each attack family is sequentially withheld from the training phase and appears solely during evaluation as an unstudied (unseen) zero-day threat.

Hypothesis 1 (RQ1: Quantization & Edge Efficiency)

  • H0 (Null Hypothesis): INT8-quantized GNN does not reduce median inference latency by ≥ 30% relative to FP32 GNN, or achieves it but precision on unseen attacks drops below 0.92 / Macro-F1 drops by more than 0.02 (absolute).
  • H1 (Alternative Hypothesis): INT8-quantized GNN reduces median inference latency by ≥ 30% and peak memory / model size by ≥ 40% relative to FP32 GNN, while maintaining precision on unseen attacks ≥ 0.92 and Macro-F1 degradation ≤ 0.02 (absolute) (Wilcoxon signed-rank test, p < 0.05).

Threshold Justification (H1): In Task 1's literature synthesis, benchmarked studies demonstrated a −38% latency reduction (quantized GNN, IEEE 11424563) and a −45% memory saving (lightweight Edge-GNN, IEEE 11219271). A 30% threshold provides a conservative, reproducible margin. Phrasing "up to 40%" from Task 1 is replaced with a strict one-sided lower bound.

Quantum Model Status (qgnn): The quantum model executes on a classical statevector simulator; its simulated latency and memory are not directly comparable to physical edge micro-nodes. It is incorporated as an exploratory comparative baseline (descriptive statistics) rather than as a confirmatory component of H1.

Hypothesis 2 (RQ2: Topological Generalization Advantage)

  • H0 (Null Hypothesis): GNN models operating on flow interaction graphs do not provide a statistically significant Macro-F1 gain on unseen attacks ≥ 0.15 over flat feature baselines, or the observed gain is statistically insignificant (p ≥ 0.05).
  • H1 (Alternative Hypothesis): GNN models operating on flow interaction graphs improve Macro-F1 score on unseen attacks by at least 0.15 (absolute) over flat feature baselines with statistical significance (Wilcoxon signed-rank test, p < 0.05), while maintaining a False Positive Rate no higher than baseline (FPRGNN ≤ FPRflat).

6. Assumptions and Limitations

  1. Graph Construction Topology: Graphs are constructed under the scheme "flows = nodes, edges connect consecutive flows originating from the same host IP". Topological sensitivity was noted in Task 1 as an inherent research consideration.
  2. Iterative Progression: Weeks 5-6 harness implements parameter-free normalized neighbor propagation with linear classification heads. Full-scale PyTorch Geometric architectures and QAT are integrated in Week 7.
  3. Verification Sample Data: The data/sample/flows_sample.csv file (10 rows) serves strictly as an operational smoke test.
  4. Task 1 Alignment: References to "energy efficiency" in the Task 1 Bridge Statement have been strictly removed to ensure complete alignment with experimental variables.
